Scan all current question files in this repo.

Question files are numbered problem files, for example:

- unionFind/1202.py
- Graph/934.py
- Graph/BFS/542.py

If a new question file exists but is missing from coding_times, add it to coding_times with initial value 0.

If a question file has been removed from the repo, remove that entry from coding_times.

If the same problem number appears in multiple files within the same category, include it only once in coding_times.

For example, Heap/295.py and Heap/295(hard_another_method).py are the same problem. Prefer the plain filename, such as Heap/295.py, when it exists. Otherwise, use one existing filename for that problem number.

Keep existing values unchanged.

Group questions by big category or directory, and separate each category with one blank line.

Do not include non-question files like:

- basic
- python_basic
- zip_explain
- coding_times
